# 知识库维护与更新

> 发布日期：2026-10-05。内容性质：知识库维护说明。

维护面向知识质量，不设计持牌机构的运营流程。

| 变化 | 维护动作 |
|---|---|
| SFC 新文件或更正 | 实际阅读官方文本后更新定位、适用范围与覆盖映射；发现入口不等于内容核实 |
| 工具版本或许可变化 | 更新官方来源、适用版本、示例与限制；失效或不再适合的方法保留替代路径 |
| 方法或演算错误 | 修正结论，检查关联专题；由版本控制记录项目改动 |
| 页面合并或删除 | 登记旧路径与新入口，验证构建后跳转，不让旧制度内容继续出现在搜索中 |

项目版本控制记录修订历史；内容页不重复维护逐页编辑日志。来源版本与核实日期继续记在[来源登记册](../source-register.csv)。

来源核实日期仅在实际核实时更新。未运行工具的例子不得标为实测；待核实的功能不作为推荐理由。

项目健康依据可获得的流量、引用、有效贡献、问题解决情况及维护负担判断；没有数据时不虚构增长。站点维护 CI 不属于本库要设计的机构工作流。

活动页面按[覆盖矩阵](../coverage.md)与[编辑标准](content-standard.md)复核。中文正文优先；英文首页、导航和核心专题摘要保持一致。保持 MkDocs，避免额外自建平台的维护负担。
