# 知识库首版说明

> 发布日期：2026-10-05。内容性质：知识库维护说明。

## 首版定位与范围

本知识库首版定位于概念、方法和现有工具。机构内部的台账、评分卡、审批、报告、底稿和治理工作流不属于产品内容；相关风险机制以可复核的知识专题呈现。

首版包含知识地图、能力覆盖矩阵、评估基础、隐私、公平性、漂移等知识入口，以及 RAG、提示注入、Agent 权限与模型裁判教学专题。工具区分软件、框架、商业产品及源码可见产品。自编例子与监管附录示例分开。
