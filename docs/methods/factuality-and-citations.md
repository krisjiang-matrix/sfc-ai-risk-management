# 事实与引用核查：声明支持、来源适用与重大遗漏

回答中的赎回页码引用准确，却把产品风险写低、补上来源没有的奖项，仍可能误导读者。**事实与引用核查把已陈述内容拆成可验证声明，再分别检查来源支持、引用匹配和必需信息遗漏。** 一条引用正确，不说明整篇回答真实或完整。

24EC55第13(c)段涉及端到端测试，第18(a)段涉及高风险用例的强化事实验证；附录第9–10段说明检索与整合错误及引用限制，适用依据见[通函导读](../regulatory/24EC55.md)。本文的逐声明计量为参考方法。

## 源资料和问题日期限定核查范围

<div class="method-comparison-table" markdown="1">

| 输入项 | 说明 | 关联证据 |
|---|---|---|
| 模型输出文本 | 待核验的完整模型响应，关联问题和系统版本 | 输出记录及运行元数据 |
| 指定参考资料 | 模型输出应依据的资料，包含可识别的版本或日期 | 源文件、段落或页面 |
| 预期答案与原子事实 | 预先定义的可接受答案及必须覆盖的事实（参见 [gold-standard-design.md](gold-standard-design.md)） | 金标准记录 |
| 实际检索内容（如适用） | RAG 系统返回的文档片段及输出中的引用 | 检索日志和引用位置 |

</div>

先确认资料可读取、版本和适用日期明确，回答能够关联问题与系统配置。源文档能说明它记载了什么，但是否代表外部事实仍需另行确认；过期或不适用资料不能因页码匹配就成为有效依据。专业推断和歧义应保留判定理由。

## 完整教学案例展示引用正确仍存在误导

"青岚资产管理"、"青岚稳健增长基金"、"李核验"均为虚构。

**场景（合成）：** 检查 RAG 输出是否忠实于《青岚稳健增长基金产品资料概要》2025-06-01 版。以下页码内容均为教学假设：第1页列产品名称、ISIN、成立日、基金类别和基金经理“王明”；第2页列管理费、托管费和投资范围（亚太蓝筹股、投资级债券）；第3页列赎回到账区间；第4页列 R4 中高风险及不保证本金和最低收益；第5页列自成立以来年化回报 6.48%。资料未提及经理资历或奖项，也没有定义“稳健型”的可核验标准。

> 青岚稳健增长基金（ISIN: HK0000123456）成立于2020年3月15日，是一只混合型基金。该基金管理费为1.2%，托管费为0.15%，主要投资于亚太地区的蓝筹股和投资级债券。基金由资深基金经理王经理管理，历史年化回报率约为6.5%。该基金在2024年获得"最佳混合型基金"奖。
>
> 根据产品说明书第3页，该基金的赎回资金一般在T+3至T+5个工作日到账。
>
> 总体而言，这是一只风险较低的稳健型产品。

AF-9 与 AF-10 分开计分：基金经理身份只得到部分支持；“资深”没有参考依据。不能因句子其余部分有依据，就把整句判为已验证。

一条句子可以同时包含姓名、资历和评价，需分别判定。声明可按数值、实体、关系或引用分类；建议和预测不应伪装成能够按当前资料确认的事实。

对每条原子事实，给出以下判定之一：

<div class="method-comparison-table" markdown="1">

| 判定 | 定义 | 示例 |
|---|---|---|
| **已验证 (Verified)** | 模型输出的声明与源文档一致，且日期匹配 | 源文档显示管理费1.2%，模型也输出1.2% |
| **与源文档矛盾 (Contradicted)** | 模型输出的声明与源文档明确矛盾 | 源文档显示管理费1.5%，模型输出1.2% |
| **源文档未支持 (Unsupported)** | 源文档中未找到与该声明相关的信息 | 模型声称"该基金获多项大奖"，但源文档未提及 |
| **部分支持/信息不足 (Partially supported)** | 源文档支持声明的一部分，但缺少足以确认具体结论的细节；不得当作完全验证 | 源文档列出基金经理"王明"，模型只说"王经理"，不能据此确认完整姓名 |
| **不可验证 (Unverifiable)** | 声明本身无法通过源文档验证（如主观评价、预测） | "长期来看该基金表现将优于同行" |

</div>

## 遗漏与引用需要独立计量

重大遗漏检查

假设金标准要求回答时说明成立日期、ISIN、风险等级及本金保障边界：

✅ 成立日期和 ISIN 已覆盖；❌ **遗漏本金保障边界：** 未说明“不保证本金安全，也不保证最低收益”；❌ **未给出正式风险等级：** 没有报告 R4；AF-14 的“风险较低”又与来源直接矛盾。

遗漏检查与已陈述事实的核验分开计量。风险等级未被准确说明是覆盖缺口；“风险较低”则是另一个明确矛盾，不能重复加进原子事实分母。

引用核查逐一确认指向的段落是否支持相关声明，不能只检查链接可打开或文档存在。重要遗漏对照预先记录的必需事实；它们没有出现在回答中，不能添加到已陈述声明分母。

## 声明通过率与引用准确率不能互相替代

```text
参考源核验通过率 = N_verified ÷ (N_verified + N_contradicted + N_unsupported + N_partially_supported)
```

分子：判定为"已验证"的原子事实数；分母：对照指定源后可判定的事实数，包括与源矛盾、未支持和部分支持；排除"不可验证"类型；解释：未支持表示该参考源未提供依据，不能单独证明声明在外部世界为假。需要外部真实性结论时，另找适用的权威证据；零分母处理：如果输出中无可验证的原子事实（如纯拒答或纯建议性输出），该指标不适用（标注"N/A"）。

```text
引用准确率 = N_citations_correct ÷ N_total_citations
```

分子：引用被验证为"引用指向的源文档确实包含模型声称的信息"的次数；分母：模型中出现的引用总数；零分母处理：若模型未提供任何引用，标注"无引用"。

<div class="method-comparison-table" markdown="1">

| 指标 | 值 |
|---|---|
| 原子事实总数 | 15 |
| 可判定声明 | 14 |
| 已验证 | 10 |
| 与源文档矛盾 | 1 |
| 源文档未支持 | 2 |
| 部分支持 | 1 |
| 不可验证 | 1 |
| 参考源核验通过率 | **71.4%**（10 ÷ (10+1+2+1)） |
| 引用准确率 | **100%**（1 ÷ 1，但仅有一条引用） |
| 重大遗漏 | **是**（缺失本金保障边界及正式风险等级） |

</div>

该输出的风险判定：

1. **参考源核验通过率 71.4%**——14 条可判定声明中 10 条与指定资料一致；这不代表外部事实准确率，也没有通用及格线。该值须与错误性质和遗漏共同阅读。
2. **AF-9 仅部分支持，AF-10 与 AF-12 未获来源支持。** “王经理”不能确认完整身份；“资深”和获奖说法在这份资料中找不到依据，但“未支持”不等于已证明外部为假。
3. **AF-14 与来源矛盾。** R4 中高风险不能改写成风险较低；AF-15 的“稳健型”也缺乏可判定定义，不应伪装成客观分类。
4. **存在重大遗漏。** 未声明本金保障边界，也未报告正式风险等级；风险等级遗漏与 AF-14 的错误表述是不同问题。
5. **教学结论：** 引用准确率 100% 只说明唯一引用指向的页码与声明相符，不证明其他声明均有依据。要定位差异，需检查 AF-9 至 AF-14 对应的检索片段及引用覆盖；若资料确实未支持，则应将“未支持”保留为来源判断，而不要推断其外部真伪。

## 来源一致、外部真实与整体合适是不同结论

解释结果时需区分：

<div class="method-comparison-table" markdown="1">

| 概念 | 说明 | 验证方法 |
|---|---|---|
| **"源文档说 X"** | 验证源文档中是否确实存在 "X" 这个陈述 | 逐字对照源文档 |
| **"模型正确报告了源文档的内容"** | 验证模型的输出是否忠实复述了源文档中的信息 | 比较模型输出与源文档对应段落 |
| **"源文档支持模型的解释"** | 验证模型从源文档中得出的推论或解释是否有充分依据 | 需要 SME 判断（源文档可能同时包含支持和不支持该解释的信息） |

</div>

**常见陷阱：** 模型可能"正确报告了源文档的内容"但引用的源文档本身已过时，或模型引用的段落与问题不相关（表面引用正确，实质张冠李戴）。

已核验的另一份教学输出有8条声明：7条可判定，其中5条验证、1条矛盾、1条未支持，另1条不可验证且部分支持为0。核验比例为 `5/(5+1+1+0)=71.4%`，仍有不保本信息遗漏。相同百分比可以对应不同错误组合，不能作为独立风险结论。

本方法受领域知识、来源日期、翻译和文本覆盖限制，数值计算、代码与图表需要额外检查。少量人工核验可形成判据，大量输出可结合[分层抽样](stratified-sampling.md)与[模型裁判校准](judge-calibration.md)；自动辅助不能补足错误金标准或缺失来源。参考记录设计见[金标准设计](gold-standard-design.md)。
