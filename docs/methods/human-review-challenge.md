# 人工复核验证：错误发现与有效纠正需要分别观察

输出被标记为“已审核”，仍可能保留错误数值、风险分类或关键遗漏。**人审挑战在隔离演练中呈现预先核实的错误，观察复核者是否发现并纠正，而不是只统计审批状态。** 结果用于检查资料、界面和方法的覆盖缺口，少量盲样不能评价个人总体能力。

24EC55第18(b)段涉及高风险用例的适当对客人力审查，第19段说明有人审仍需测试与监测，脚注16保留特定场景的实施灵活性，适用条件见[通函导读](../regulatory/24EC55.md)。以下设计不是监管指定演练制度。

## 错误判据与演练条件需要事先核实

<div class="method-comparison-table" markdown="1">

| 输入项 | 说明 | 数据来源示例 |
|--------|------|--------|
| AI 输出样本或已知错误模式 | 用于设计可复核的盲样错误 | 有关输出、来源和预期答案的记录 |
| 正常审查样本 | 用于提供与真实任务相似的练习背景 | 仅在隔离演练中使用的样本 |
| 参与者匿名标识（如需个体比较） | 用于将观察结果与同一参与者关联；无此需要时可不采集 | 去标识化记录 |
| 既有挑战结果（如有） | 用于比较相同评分规则下的观察变化 | 历次演练记录 |

</div>

盲样是外观接近正常内容、但包含预置错误的练习输出。使用隔离队列和合成或脱敏资料，不触发真实对客发送或实际动作。参与者理解演练目的与数据使用，但不依靠具体题目或出现规律猜测错误。

预置错误应符合实际任务特征，并由独立依据核实。过于明显的题目难以说明实质检查效果；所有人都未发现的题目应先核对真值和资料，也可能反映共同盲区，不能为提高分数而删除。

错误类型与设计条件对应如下：

<div class="method-comparison-table" markdown="1">

| 标准 | 说明 |
|------|------|
| **真实性** | 错误类型应是实际可能出现的问题——太明显的错误（如将「1+1=3」）缺乏诊断价值 |
| **可检测性** | 有能力的审查人在正常审查时间内应能发现——如果所有审查人都无法发现，检查真值和可用资料，也考虑共同盲区；不能据此认定样本设计错误或排除该样本 |
| **多样性** | 覆盖不同类型的错误（数值偏差、实体错误、合规缺失、引用错误、误导性措辞） |
| **严重程度分级** | 包含轻微错误和严重错误，以评估审查人对不同严重程度的敏感度 |

</div>

<div class="method-comparison-table" markdown="1">

| 错误类型 | 植入方法 | 严重程度 | 示例 |
|----------|----------|----------|------|
| 数值偏差 | 将正确数值替换为错误数值 | 中-高 | 回报率6.48% → 8.5% |
| 实体错误 | 替换产品名/人名/代码 | 中 | 基金经理「王明」→「李明」 |
| 合规缺失 | 删除必需要素（如风险声明） | 高 | 移除「不保本」声明 |
| 引用错误 | 将来源内容误写或错配到引用位置 | 高 | 来源写“赎回资金T+3至T+5个工作日到账”，盲样引用该页却写成T+0 |
| 误导措辞 | 调整措辞使内容产生误导 | 中 | 「中高风险」→「风险适中」 |
| 过期信息 | 使用已过时的数据 | 中 | 把旧版本数值当作当前值引用 |

</div>

## 同一组盲样展示遗漏与数值错误的检出差异

教学演练由A、B、C三个匿名参与者分别检查五条盲样，每条仅植入一个有效错误。机构、参与者和数据均虚构，样本不进入生产队列。

<div class="method-comparison-table" markdown="1">

| 盲样 | 预置错误 | 类型 | 教学严重度 |
|---|---|---|---|
| B-1 | 回报率8.5%，源资料为6.48% | 数值偏差 | 高 |
| B-2 | 风险等级写为R2，源资料为R4 | 风险分类 | 高 |
| B-3 | 删除不保本声明 | 重大遗漏 | 高 |
| B-4 | 写成T+0到账，资料为T+3至T+5工作日 | 引用错误 | 高 |
| B-5 | 王明被替换为李明 | 实体错误 | 中 |

</div>

<div class="method-comparison-table" markdown="1">

| 参与者 | B-1 | B-2 | B-3 | B-4 | B-5 | 检出比例 | 平均时间 |
|---|---|---|---|---|---|---|---|
| A | 未检出 | 检出 | 未检出 | 未检出 | 检出 | 2/5=40% | 1.4分钟 |
| B | 检出 | 检出 | 检出 | 检出 | 检出 | 5/5=100% | 6.2分钟 |
| C | 检出 | 检出 | 未检出 | 检出 | 未检出 | 3/5=60% | 3.5分钟 |

</div>

按盲样汇总，B-1为 `2/3≈67%`，B-2为 `3/3=100%`，B-3为 `1/3≈33%`，B-4与B-5各为 `2/3≈67%`。本例缺失不保本声明仅被B发现，提示需要检查遗漏判据和资料呈现；单个题目不能证明这种错误普遍更难发现。

## 分母按有效错误与参与者观察固定

若一条盲样包含多个可独立判定的错误，需按错误计分，而非只按盲样是否失败计分。

检出率定义为发现的有效预置错误数除以应检查的有效错误总数。分母由测试前独立核实的错误决定，不因所有人没发现而调整。确属设计无效的题目应记录原因，并同时披露调整前后的结果。

整体检出数 `2+5+3=10`，分母 `5×3=15`，比例约67%。同一题被多人复核使观察相关，不能按15个独立二项样本估计总体能力。

## 判定、修改与最终内容构成纠正证据

记录每份盲样的审查结果：

<div class="method-comparison-table" markdown="1">

| 观察项 | 说明 |
|--------|------|
| 审查结论 | 审查人是「通过」「修改后通过」还是「退回」？ |
| 是否发现植入的错误 | 审查记录中是否指出了预置的错误？ |
| 修改内容 | 如果审查人做了修改，是仅修改了表面问题还是纠正了实质错误？ |
| 审查时间 | 审查该条盲样花费的时间 |
| 审查备注 | 审查人留下的注释和说明 |

</div>

“修改后通过”可能只修正语气，没有改正错误事实。需要把修改前后文本与源依据关联，分别记录发现和纠正。A对未检出的B-1、B-3、B-4均留有“已审核，无问题”，对B-2与B-5有问题记录；这说明本次检查的可见差异，不足以认定形式化审查。

B本轮五题全检出，但不能推断总体检出率100%。6.2分钟/条能否持续，还需结合工作量和任务条件。时间与检出比例的关联并不证明个人能力差异，题目难度、负荷和资料便利性都可能影响结果。

## 方法改进需要难度可比的后续对照

可比较辅助信息、界面高亮或检查提示前后的效果，保留同一判据、题目难度和样本量。反馈应解释具体错误与核查依据，不以少量结果处罚个人，也不把“更仔细”当作改进方法。

盲样仅覆盖预定义错误，不能穷尽新型问题；参与者对规律的额外警觉也可能影响结果。人审概念见[人机交互](../concepts/human-ai-interaction.md)，盲样依据见[事实与引用核查](factuality-and-citations.md)。本方法没有指定软件；隔离呈现、前后文本记录和可复核评分缺一不可，审批计数不能替代这些证据。
