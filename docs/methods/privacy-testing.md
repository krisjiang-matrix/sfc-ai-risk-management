回答中没有出现客户姓名，并不意味着隐私边界有效。数据可能已进入未授权检索结果、模型输入、工具参数或日志。**隐私测试需要沿数据流分别观察检测、访问和暴露，而不是只检查最后一段文字。** 训练数据隐私攻击又涉及不同前提，不能与运行时泄漏混称。

## 数据路径与访问身份构成运行时测试依据

假设客户资料查询系统只允许身份A读取自己的记录。准备虚构记录、测试身份、预期访问边界和各阶段可观察输出，在输入、检索、提示、日志与输出放置可追溯标记，例如 `SYNTH-SECRET-A17`。分别运行有权限与无权限请求，核对标记实际到达的位置。

标记属于教学数据，不使用真实个人资料来增强“真实性”。最终回答未显示标记，只说明这次展示没有该字符串；若模型输入或日志已收到未授权内容，泄漏路径仍存在。测试还应关注摘要、片段、标题与关联元数据，单一标记未出现不能证明没有间接暴露。

## 检测精度与泄漏比例使用不同分母

敏感实体检测用于识别姓名、电话、账户等内容，脱敏转换用于遮蔽或替换检测出的实体。检测并非授权判断：一段资料识别为敏感，不代表每位使用者都不能读取；反之，未被检测的内部记录仍可能受权限限制。

教学样本包含30个敏感实体、70个普通实体。检测命中24个敏感实体、漏检6个，普通实体误报7个、正确放过63个。

| 计量对象 | 计算 | 解释 |
|---|---|---|
| 检测精确率 | `24/(24+7)=77.4%` | 被标为敏感的31个实体中24个确为敏感 |
| 检测召回率 | `24/30=80%` | 30个敏感实体中找到24个 |
| 检索越权率 | `3/20=15%` | 另一组20个未授权请求中3个取得虚构秘密 |
| 输出泄漏率 | `1/20=5%` | 同组请求中1个最终展示虚构秘密 |

检测样本和请求样本的单位不同，不能合并成一个准确率。检索越权率高于最终输出泄漏率时，不能只呈现后者：数据已经越过访问边界，后续回答遮蔽不能修复此前暴露。姓名、电话、账户及中文表达还应分别检查，汇总值可能掩盖特定实体漏检。

## 训练成员推断需要已知对照与匹配条件

成员推断试图判断某条记录是否用于训练，不要求输出完整原文。模型反演、训练内容提取和成员推断是不同攻击目标，接口条件也不同。黑盒API的训练来源未知时，应明确哪些前提无法验证，而不把模型猜测当成参训证据。

教学对照有20个已知成员和20个非成员。攻击判断命中成员12个、误判非成员8个，得到 `TPR=60%`、`FPR=40%`，这个阈值下的优势为20个百分点。必须说明成员定义、两组样本如何匹配及可访问的攻击接口；这组演算不能证明某个真实个人曾参训。

## 替换后的可识别性与记录边界仍需复核

脱敏后要检查替代值是否保留跨记录链接，或能被上下文重新识别。假名化记录可能仍然包含足够组合特征；敏感实体检测成功也不能证明所有间接标识已经消除。虚构标记适合检查运行路径，不能证明模型没有记忆真实训练资料。

SFC [24EC55附录第14–17段](https://apps.sfc.hk/edistributionWeb/api/circular/openAppendix?lang=EN&refNo=24EC55&appendix=0)涉及不同隐私攻击与第三方数据使用；本页演算属于参考方法。数据流及第三方边界见[数据与隐私](../concepts/data-and-privacy.md)。
