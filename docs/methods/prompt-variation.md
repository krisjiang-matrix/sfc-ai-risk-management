# 等价问法测试：核心答案稳定与事实正确的区别

用户把简体问题改成繁体，产品年度回报率却从8.2%变成4.1%。这样的差异需要核对检索、上下文和生成，而不是只检查回答文本是否相同。**等价问法测试保留问题含义，改变表达形式，观察核心事实与结论是否稳定。** 一致回答也可能全部错误，稳定性与准确性须分别核验。

<p class="article-meta">参考方法 · 本文更新：2026-10-11 · 来源核实：2026-09-30 · 合成教学材料，未执行测试，不构成统一阈值、频率或职责要求。</p>

## 语义等价是对照成立的前提

在评估两个答案是否"一致"时，**精确文本匹配（exact text match）**是错误的标准，原因如下：

<div class="method-comparison-table" markdown="1">

| 问题 | 说明 |
|------|------|
| 同义表述 | "管理费为 1.5%" 和 "每年收取 1.5% 的管理费"在实质上相同，但字符串不匹配 |
| 顺序差异 | 列表顺序重排不影响实质，但字符串不匹配 |
| 格式差异 | 答案用数字列表 vs 用自然段落表达，不一定意味着实质差异 |
| 补充信息 | 一个答案较另一个多了合理的背景说明，不意味着矛盾 |

</div>

应以**答案的实质等同性（substantive equivalence）**为评判标准：两个答案在核心事实（core facts）、结论（conclusion）、建议（recommendation）上是否一致。

等价复述、顺序和格式改变可以用于同题对照；添加新日期、资格条件或要求则可能改变问题。组合语言与格式变化时，结果只能归因于组合挑战，不能直接判为单项语言缺陷。用例和答案范围应先确定，评分不只比较字符串。

## 同题教学对照保留资料与独立会话

为每个问题设计足以覆盖相关变化类型的等价问法，并提前定义**可接受答案范围（acceptable answer range）**。不要求每题都覆盖所有类型。组合语言、格式等多个变化时，将它标为组合挑战；结果只能归因于整组变化，不能单独归因于其中一项。

合成示例 — 一个问题及其 5 个变体:

<div class="method-comparison-table" markdown="1">

| 变体 ID | 变体文本 | 变体类型 | 可接受答案范围 |
|---------|---------|---------|--------------|
| V0（原始） | 青岚稳健增长基金2025年的全年回报率是多少？ | — | 回报率：8.2% ± 0.1%（数据与容差均为教学假设） |
| V1 | 请问青岚稳健增长基金2025年的全年回报率是多少？ | 类型 1: 等价复述 | 同 V0 |
| V2 | 我正在整理2025年度投资记录，想核对青岚稳健增长基金在该年度的全年回报率。 | 类型 5: 详细程度 | 同 V0 |
| V3 | 2025年全年回报率：青岚稳健增长基金 | 类型 3: 格式变化 | 同 V0 |
| V4 | What was the Qinglan Steady Growth Fund's full-year return in 2025? | 类型 4: 语言变体 | 同 V0 |
| V5 | 青嵐穩健增長基金2025年的全年回報率是多少？ | 类型 4: 繁体语言变体 | 同 V0 |

</div>

对每个变体调用模型，记录完整输出。确保每个变体在**独立的会话**（isolated session）中执行，避免前一次调用的上下文影响后续结果。

将每个变体的答案与可接受答案范围比对:

<div class="method-comparison-table" markdown="1">

| 变体 ID | 模型输出 | 实质判断 | 是否通过 |
|---------|---------|---------|---------|
| V0 | 青岚稳健增长基金2025年的年度回报率为 8.2%。 | — | ✅ |
| V1 | 青岚稳健增长基金2025年全年回报率为 8.2%。 | 回报率一致 | ✅ |
| V2 | 青岚稳健增长基金在2025年实现了约 8.2% 的年度收益率。 | 回报率一致 | ✅ |
| V3 | 青岚稳健增长基金2025年全年回报率为 8.2%。 | 回报率一致 | ✅ |
| V4 | The Qinglan Steady Growth Fund achieved an annual return of 8.2% in 2025. | 回报率一致 | ✅ |
| V5 | 青嵐穩健增長基金2025年度回報率為 4.1%。 | **回报率 4.1% ≠ 8.2%，实质不一致** | ❌ |

</div>

这个合成结果只展示了该组繁体问法与其他问法之间的差异；仍须检查检索内容、会话上下文和模型输出，才能定位原因。

本例8.2%及±0.1%的可接受范围均为教学假设。每次独立会话仍需记录资料版本、实际上下文和生成配置；共同条件不一致时，不能仅归因为问法变化。

## 输入通过率与问题不一致率采用不同单位

- **所有测试输入的答案通过率** = 通过的输入数 ÷ 测试输入总数；该数包括基线 V0，主要描述回答是否符合答案标准，不单独衡量变体稳定性。
  - 上述示例：5/6 ≈ 83.3%（含 V0）；只看 5 个改写变体则为 4/5 = 80%。应另报 V0 是否正确，避免把基线错误与问法敏感性混在一起。
- **每个问题的平均最大差异 (Max Deviation per Question)**: 同一问题的变体间，数值答案的（如有）最大绝对差异
  - 上述示例: `|8.2% - 4.1%| = 4.1pp`
- **实质性不一致率 (Substantive Inconsistency Rate)**: 存在至少一个变体产生实质性不同结果的问题数 / 总问题数

实质性不一致率描述本测试集上至少一次变体失败的问题比例。逐题检查语义等价性、检索、上下文与生成差异；没有适用于所有用途的统一零容忍阈值，零观测也不意味着真实失败概率为零。

合成示例 — 5 个问题的完整测试结果。下表“测试输入数”和“通过数”均包含每题的基线 V0，计量单位是单次输入；实质性不一致率按问题计量，二者不能直接互换:

<div class="method-comparison-table" markdown="1">

| 问题 | 测试输入数（含 V0） | 通过数（含 V0） | 最大差异 | 是否发现实质性不一致 |
|------|--------|--------|---------|-------------------|
| 青岚稳健增长基金2025年回报率 | 6 | 5 | 4.1pp | ❌ 是（V5 繁体变体） |
| 青岚全球配置基金的最低投资额 | 5 | 5 | $0 | ✅ 否 |
| 客户适当性匹配结果（保守型 → 产品推荐） | 5 | 5 | 0 个产品差异 | ✅ 否 |
| 管理费与赎回费说明 | 4 | 4 | 0pp | ✅ 否 |
| 投资展望中的行业观点 | 4 | 3 | 实质判断差异 | ❌ 是（V2 格式变体产生了更激进的表述） |

</div>

**实质性不一致率**: 2/5 = 40%。这是五个教学问题的结果；还需逐题解释差异和样本代表性。

全体输入通过率为 22/24 ≈ 91.7%（包括每题一个 V0）；它回答的是 24 次输入中有多少符合答案标准，不是 24 次之间的稳定程度。稳定性信号应按问题汇总：5 题中有 2 题至少一次变体不一致，即 2/5 = 40%。

## 差异定位需要候选、上下文与输出证据

对于未通过的变体（如 V5），分析差异的可能原因：

<div class="method-comparison-table" markdown="1">

| 可能原因 | 说明 |
|---------|------|
| 知识库检索差异 | 繁体/英文问题触发了不同的检索结果（见 [RAG检索评估方法](rag-retrieval-evaluation.md)） |
| 模型歧义解读 | 模型对"回报率"的不同解读（绝对回报 vs 超额回报） |
| 语言模型偏差 | 跨语言时模型依赖了不同的训练数据记忆 |
| 格式诱导 | 格式变化导致模型跳过了某些推理步骤 |

</div>

这些是待检查的假设。应核对各变体实际检索到的资料、完整输出和会话条件，再判断差异来自哪里。

繁体变体失败只显示本组观察，不证明繁体模型普遍较差。先核验问题翻译与等价性，再比较实际检索材料及上下文，必要时固定证据进行生成对照。对随机输出保留重复运行的逐题变化，不把改写当成独立人群。

## 一致性测试不能替代事实与安全评估

<div class="method-comparison-table" markdown="1">

| 不能证明 | 原因 |
|---------|------|
| 对抗鲁棒性 | 等价变体 ≠ 恶意构造。即使所有等价变体都通过，模型仍可能被精心设计的 prompt injection 攻击。对抗鲁棒性需用 [对抗测试方法](adversarial-testing.md) 独立评估。 |
| 语义操控（semantic manipulation） | 提示变体测试的是表面形式变化，不测试语义层面的操控（如"假如你是"角色诱导、"忽略之前的指令"覆盖攻击）。这是 [对抗测试方法](adversarial-testing.md) 的覆盖范围。 |
| 事实准确性 | 所有变体返回一致答案 ≠ 答案是正确的。一致性测试的是稳定性（stability），而非准确性（accuracy）。准确性需用 [RAG生成评估方法](rag-generation-evaluation.md) 评估。 |
| 延迟一致性 | 变体可能因检索路径不同而导致响应延迟差异，本方法不衡量性能指标 |

</div>

相关诊断见[检索评估](rag-retrieval-evaluation.md)、[生成评估](rag-generation-evaluation.md)及[对抗测试](adversarial-testing.md)。本页不绑定软件，批次运行和逐题记录可支持比较，但语义等价与事实判据仍需独立核实。
