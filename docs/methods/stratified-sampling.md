# 分层抽样：子群覆盖与总体估计的区别

难题或投诉在全部输出中占比较低，却可能具有更严重的错误后果。**分层抽样在各类输出中分别随机取样，既观察这些子群，又用总体权重解释总体表现。** 过采样后的简单比例描述样本构成，不自动等于真实总体错误率。

24EC55第18(b)段涉及高风险用例的适当人力审查，适用条件见[通函导读](../regulatory/24EC55.md)。本页讲解抽样测量，不能由抽样统计设计推导它可以替代适用的人审要求。

## 总体清单与分层标签决定抽样对象

<div class="method-comparison-table" markdown="1">

| 输入项 | 说明 | 数据来源示例 |
|--------|------|--------|
| 输出总体清单 | 目标窗口内所有符合范围的 AI 输出（含唯一 ID、时间和类型） | 可核对的输出记录 |
| 分层标签 | 每条输出按预先定义的维度标注，如输出类型或风险类别 | 原始字段或可复核的标注 |
| 审查资源约束 | 可用样本量、每个样本的审查成本及可用标签 | 项目约束和测量记录 |

</div>

明确审查窗口的范围：

明确起止日期的观察窗口（避免“最近一段时间”等边界不明的范围）；输出类型（如「所有AI生成的客户研究报告」）；排除标准（如排除已撤回的输出、内部测试输出、非AI生成的输出）。

> 总体 = 某合成系统在指定观察窗口内生成的4,140条客服回复
> 排除：17条已撤回会话、3条内部测试输出
> 有效总体：N = 4,120条

选择与审查目标最相关的分层维度：

<div class="method-comparison-table" markdown="1">

| 分层维度 | 适用场景 | 层示例 |
|----------|----------|--------|
| 风险等级 | 通用 | 高、中、低 |
| 输出类型 | 不同类型有不同错误模式 | 投资建议、产品信息、市场分析、客户服务 |
| 客户群体 | 不同客户类型的错误影响不同 | 高净值、机构、零售 |
| 时间窗口 | 比较系统在不同阶段的表现 | 按评估问题需要划分的时段 |
| 历史表现 | 对已知问题区域加重抽样 | 高错误率输出类型 vs 低错误率输出类型 |

</div>

分层维度应对应要解释的风险差异；层数过多会减少每层样本并使估计不稳定，没有通用的层数上限；小层不应为了满足任意数量门槛而自动合并。只有在业务含义相近且合并不会掩盖目标风险时才合并；否则保留该层并报告样本量和不确定性；分层应基于审查前可用的信息（如输出类型），不能按待估计的错误结果分层，否则会改变抽样目标。

排除撤回输出会改变估计目标，是否排除应与评估问题一致，不能为减少错误而事后选择。层内随机抽样依赖可核对的总体和可靠标签；便利取样不能因贴上分层标签就获得代表性。

## 规划样本量需要精度与设计假设

样本量取决于期望的精度、置信水平和预期变异性。

对简单随机不放回抽样的二元错误比例，作初步样本量规划可假设 `z=1.96`（双侧95%）、`p=0.5`（未知比例时的保守取值）、`e=0.05`（目标绝对误差5个百分点）：

```text
n0 = z² × p × (1-p) / e² = 384.16
n = ceil(n0 / (1 + (n0-1)/N))
```

<div class="method-comparison-table" markdown="1">

| 有限总体 N | 向上取整的规划样本量 n |
|---|---|
| 100 | 80 |
| 500 | 218 |
| 2,000 | 323 |
| 4,120 | 352 |

</div>

这些数值基于正态近似与概率抽样前提，不是每种分层设计均达到同一精度的保证。分层后的方差需按各层权重、层内样本量和有限总体修正单独计算；小比例或小样本可使用更合适的区间。总体小于100仍可抽样，是否全量检查取决于所需精度与成本。

## 过采样增加子群观察但改变简单比例

- **比例分配 (Proportional Allocation)**：各层样本量按总体比例分配
  - `n_h = n × (N_h / N)`
- **过采样 (Oversampling)**：对高风险层或小层分配更大的抽样比例
  - 原因：错误后果更严重的层应被更充分地审查
  - 在计算总体估计时需要按权重调整

<div class="method-comparison-table" markdown="1">

| 层 | 总体(N_h) | 占比 | 比例分配 | 过采样分配 | 最终样本量 |
|----|----------|------|---------|-----------|-----------|
| 产品信息 | 2,472 | 60% | 60 | 50 | 50 |
| 账户查询 | 1,236 | 30% | 30 | 25 | 25 |
| 投诉/纠纷 | 412 | 10% | 10 | 25 | 25 |
| **合计** | **4,120** | **100%** | **100** | **100** | **100** |

</div>

投诉/纠纷层过采样——虽然仅占总体10%，但该层错误影响更严重，需要更充分地审查。

合成总体 N=4,120，抽取 n=100；投诉/纠纷层被过采样。每条输出按最高严重度只归入一个类别：

<div class="method-comparison-table" markdown="1">

| 层 | 样本 | 无错误 | 轻微错误 | 严重错误 | 有错误输出率 |
|---|---:|---:|---:|---:|---:|
| 产品信息 | 50 | 47 | 3 | 0 | 3/50 = 6.0% |
| 账户查询 | 25 | 24 | 1 | 0 | 1/25 = 4.0% |
| 投诉/纠纷 | 25 | 20 | 3 | 2 | 5/25 = 20.0% |
| **合计（未加权）** | **100** | **91** | **7** | **2** | **9/100 = 9.0%** |

</div>

总体加权估计 = 0.6×6% + 0.3×4% + 0.1×20% = **6.8%**。9.0%描述过采样后的样本；6.8%使用各层在总体中的比例恢复总体估计。这里“有错误输出率”的分子是至少有一项错误的输出数；如果还要计量单条输出中的错误项数，应另报错误项数。

## 层内随机选择与审查记录支持复核

在各层内独立进行随机抽样。记录种子及抽样实现，帮助重现选择过程。

记录随机种子（如合成值 `seed=731`）；相同种子、总体顺序、随机算法及软件版本才可能重现同一抽样结果；仅记录种子不足以复现；可将总体快照和抽样参数一并保留，以便核对抽样是否按预设规则执行。

Python可使用 `random.Random(seed).sample(population, n)`；`random.sample`没有`seed`参数。其他统计工具需确认其随机与抽样机制；在层内不放回抽样。

| 字段 | 内容 |
|------|------|
| 抽样ID | SAMP-001 |
| 总体定义 | 指定观察窗内的 AI 客服回复（N=4,120） |
| 分层方案 | 按输出类型分3层，投诉/纠纷层过采样 |
| 总样本量 | 100 |
| 随机种子 | `731` |
| 排除项 | 17条撤回会话、3条内部测试 |
| 抽样执行日期 | 记录实际日期 |

</div>

<div class="method-comparison-table" markdown="1">

| 输出ID | 层 | 抽样序号 |
|--------|-----|---------|
| OUT-042 | 产品信息 | 1 |
| OUT-043 | 产品信息 | 2 |
| ... | ... | ... |

</div>

抽样完成后，按层汇总审查结果。分析差异是否具有实际意义——不能仅看数字，需判断错误的严重程度。

记录软件、算法、总体顺序和种子，共同核对选择过程。相同种子配上不同总体顺序仍可能产生不同样本；只保存种子而不保存总体快照，不能证明抽样可复现。

## 报告类型案例说明零错误观察的局限

某合成 AI 研究系统在指定观察窗口内生成623份报告；本例检查人工复核后仍存在的事实错误，不提供机构工作流或固定频率。

<div class="method-comparison-table" markdown="1">

| 参数 | 值 |
|------|-----|
| 总体 | 指定观察窗内的 AI 研究报告（N=623） |
| 审查目标 | 验证人审实质性——人审后是否还有未发现的事实错误 |
| 分层维度 | 按报告类型：行业分析（45%）、个股研究（35%）、宏观策略（20%） |
| 总样本量 | 80（演算用样本量，不宣称达到某一置信度及±5%误差） |
| 层内分配 | 按比例，不进行过采样 |
| 随机种子 | `919` |

</div>

<div class="method-comparison-table" markdown="1">

| 层 | 总体 | 占比 | 样本量 | 发现未经人审查出的事实错误 |
|----|------|------|--------|--------------------------|
| 行业分析 | 280 | 45% | 36 | 2（5.6%） |
| 个股研究 | 218 | 35% | 28 | 4（14.3%） |
| 宏观策略 | 125 | 20% | 16 | 0（0.0%） |
| **合计** | **623** | **100%** | **80** | **6（7.5%）** |

</div>

按总体层占比加权的估计为 `0.45×(2/36) + 0.35×(4/28) + 0.20×(0/16) ≈ 7.5%`。本例按比例分配且四舍五入后与简单样本比例接近；若各层抽样比例不同，不能直接用 6/80 代替总体估计。

个股研究层样本错误率4/28≈14.3%，观察值高于其他层，但尚未进行显著性检验；较多具体数值可能是原因之一，需逐例验证，不能从汇总比例直接确定根因；可比较加入独立数值核验前后的检出效果，同时保留题目难度和样本量，以检验方法是否改善；**但要注意**：宏观策略层样本仅16份，0错误不意味着「宏观策略最安全」——可能只是小样本未能捕获错误。

## 区间精度、相关性与选择偏差限定推断

1. **样本小通常意味着区间宽。** 10个独立样本中发现2个错误（20%），二项比例的Clopper–Pearson精确95%区间约为2.5%–55.6%。是否足以支持决定取决于具体问题，30不是硬门槛。

2. **未知总体需明确抽样机制。** 未知最终规模的连续数据仍可采用概率抽样或流式抽样推断；便利抽样和缺失记录则可能有选择偏差。只有已知有限总体时才可应用上面的有限总体修正。

3. **置信区间不是安全证明。** 95%置信描述按同一有效方法重复抽样时区间的长期覆盖率；不意味着未检查输出有95%概率安全，也不直接给出这一个已得到区间包含真实值的概率。

4. **小层报告不确定性。** 小样本层依然可计算区间，但精度和检验功效可能有限；零观察错误不能外推零总体错误。

5. **分层不能消除标签或选择偏差。** 分层标签错误、非随机抽样和遗漏记录都会影响估计。

重复会话或同用户多条输出可能相关，进一步影响独立样本假设。按输出计量至少一项错误，与按声明累计错误项数是不同指标，应在摘要中明确。

抽样后的核查见[事实与引用核查](factuality-and-citations.md)，人工检出方法见[人审挑战](human-review-challenge.md)。统计工具可执行随机选择和权重计算，但不能补足缺失总体或错误标签；软件实现及版本应随抽样记录保留。
