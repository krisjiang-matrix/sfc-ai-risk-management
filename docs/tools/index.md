# 工具参考：按风险能力寻找实现路径

> 核实日期：2026-10-05
>
> 页面状态：知识库索引
>
> 维护周期：官方版本、许可或能力发生重要变化时复核

先确定问题和方法，再寻找现有工具。软件自动执行部分测试，框架帮助组织问题，两者都不能替代结果解释。以下均为 [可选工具/框架]，并非 SFC 指定产品。读者可学习安装、配置和运行，也可使用人工计算理解方法。

## 开源软件

| 能力与问题 | 工具入口 | 输入 → 输出 | 主要边界 |
|---|---|---|---|
| 回答和提示变更后是否退化？ | [Promptfoo](promptfoo.md) | 提示、测试集、断言 → 逐项结果及对比 | 断言通过不等于事实正确 |
| RAG 的检索和回答分别哪里失败？ | [Ragas](ragas.md) | 问题、上下文、答案、参考 → 指标 | 模型裁判需人工校准 |
| 对抗输入能否改变系统行为？ | [garak](garak.md)、[PyRIT](pyrit.md) | 目标接口、攻击、检测规则 → 命中与会话 | 命中需回查；未命中不证明安全 |
| 如何评估过滤器与防护效果？ | [NeMo Guardrails](nemo-guardrails.md) | 输入、检索、输出、规则 → 放行或阻断 | 测试误拒与漏拦，不能代替工具授权 |
| 输入输出含有哪些敏感信息？ | [Presidio](presidio.md) | 文本、识别器 → 实体位置及脱敏文本 | 漏检、语言覆盖和再识别仍存在 |
| 不同群组的错误率是否不同？ | [Fairlearn](fairlearn.md) | 真值、预测、群组 → 分组指标 | 指标选择与小样本影响结论 |
| 输入分布及质量是否变化？ | [Evidently](evidently.md) | 参考集、当前集 → 漂移报告 | 数据漂移不等于性能下降 |
| 如何重现评测并关联版本？ | [MLflow](mlflow.md) | 参数、指标、产物 → 可比较实验 | 记录存在不证明评测设计有效 |
| AI 应用依赖了哪些软件组件？ | [Syft](syft.md)、[Dependency-Track](dependency-track.md) | 包或镜像 → SBOM → 漏洞匹配 | 不覆盖模型权重、训练数据或业务逻辑 |

## 可查阅源码的软件与商业服务

| 能力 | 参考 | 类型和前提 |
|---|---|---|
| LLM、检索与工具链观测 | [Phoenix](phoenix.md) | 核心 ELv2，可自行部署；提供托管服务的许可受限制，单列避免混同开放许可软件 |
| RAG 自动评分 | [Azure AI 评估器](azure-rag-evaluators.md) | SDK 与云服务分开考虑；云端调用可能收费并传输上下文 |
| 数据发现和分类 | [Microsoft Purview](purview.md) | 商业平台；分类结果仍需验证范围和漏检 |

这不是采购推荐。尚无专门工具能直接证明人审有效或恢复后仍正确；利用固定测试集、人类标注和故障前后对比，见 [人与 AI 交互](../concepts/human-ai-interaction.md) 与 [第三方及韧性](../concepts/third-party-and-resilience.md)。

## 方法、数据流与结果的比较条件

从 [概念目录](../concepts/index.md) 理解机制，从 [方法目录](../methods/index.md) 选择输入和判据，再查看工具数据流、输出、许可和局限。固定版本、目标模型及裁判配置；比较时保持测试集一致，单列执行错误、漏拦、误拒和真实失败。

表格和 CSV 可帮助学习分母、分组与配对比较，见 [人工计算路径](existing-exports-and-spreadsheets.md)。机器可读映射见 [capability-map.csv](capability-map.csv)。
